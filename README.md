# Gardiyan Training – Advanced Cybersecurity Project Portfolio

This repository showcases a curated portfolio of cybersecurity projects completed during the **Gardiyan Training Program**. Each project simulates **real-world attack-defense scenarios** across enterprise, cloud, and hybrid infrastructures, integrating **automation, security engineering, advanced detection, and red/blue teaming** principles.

---

## Highlights

1. **Enterprise Active Directory Security** – Deployed and hardened a **Windows Server 2022 AD** environment with automated provisioning, targeted GPOs, advanced auditing (SACLs & event tracing), least-privilege delegation, and disaster recovery validation through **Recycle Bin** and **authoritative restores**.  

2. **Blockchain-Enabled Risk-Adaptive Compliance System** – Designed a **smart contract–driven compliance framework** integrating blockchain-based audit trails, automated policy enforcement, and adaptive risk scoring for regulatory adherence.  

3. **Cloud Malware Reverse Engineering & Containment** – Analyzed malicious binaries in a controlled cloud lab, performed **dynamic & static analysis**, reverse-engineered payload logic, and implemented cloud-native containment strategies.  

4. **Cross-Platform Keylogger with Covert Exfiltration** – Developed a **C-based keylogger** for Windows & Linux with **AES-encrypted log storage**, HTTPS/DNS-based exfiltration, and forensics evasion via system-level stealth.  

5. **Custom Threat Emulation Platform in Python** – Built a modular framework to simulate advanced persistent threats (APTs) with configurable payloads, C2 channels, and evasion techniques for SOC training.  

6. **DNS Sinkhole for Domain-Based Threat Hunting** – Implemented an **internal DNS sinkhole** to capture malicious domain requests, integrated logs into SIEM, and correlated events for proactive detection.  

7. **Decrypting HTTPS Traffic Using SSLsplit** – Deployed SSLsplit in a controlled lab to intercept and decrypt TLS traffic for forensic analysis, simulating lawful inspection scenarios.  

8. **Red Team Automation Suite with Detection Bypass** – Created automated red team scripts for reconnaissance, exploitation, and post-exploitation while embedding **sandbox evasion** and **signature obfuscation**.  

9. **Security Misconfiguration Analysis in Terraform** – Audited Infrastructure-as-Code for misconfigurations, identified exploitable defaults, and automated remediation checks.  

10. **Web Application Firewall (WAF) Testing Tool** – Engineered a custom WAF testing utility for payload fuzzing, bypass detection, and rule validation across multiple frameworks.  

11. **Zero Trust Security with Docker & Live Blocking** – Designed a containerized zero-trust architecture with **real-time policy enforcement**, network segmentation, and malicious session termination.
